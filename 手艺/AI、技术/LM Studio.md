**关于 LM Studio 0.4.2 版本更新与使用教程的整理**

LM Studio 本质是大语言模型的加载器，最大优点是直观友好的 UI 页面，部署极简单，下载安装包直接安装即可。支持 N 卡、A 卡、英特尔显卡，内置模型下载与管理功能，后端服务稳定简洁，能同时加载并调用多个模型。缺点：本质是 llama.cpp 套壳，只能加载 GGUF 格式模型，软件本身属半开源。

**与其他工具对比**

相比 Ollama：两者都是 llama.cpp 套壳，但 LM Studio 对新手更友好，部署和加载流程更简单直观，无需模型转换加载。参数调整更灵活，可自由调整模型模板与系统提示词，不需命令行，所有操作在界面完成。

相比 text-generation-webUI：LM Studio 部署与上手难度更低，界面更适合初学者。但不支持那么多模型格式（原生 transformer 权重、GPTQ、EXL2 量化）。不过随着 llama.cpp 持续优化，GGUF 推理速度已不输 GPTQ 和 EXL2。GGUF 可使用内存进行显存代偿，极低配置就能运行大语言模型。

**安装**

官网点击 Download for Windows，或评论区网盘链接下载 0.4.2 版本 EXE 文件。双击安装，一路下一步。**安装文件夹必须是全英文目录**，不能含中文或特殊符号，用户名是中文的话需调整到任意英文目录，防止更新时路径错误。

**基础配置**

左下角设置 → General → 语言 → 简体中文 beta，部分 UI 汉化。

**UI 页面介绍**

左上角四个选项卡：

**第一个：聊天页面**。布局类似 OpenAI 标准对话格式，左侧聊天列表，中间对话窗口，右侧单个会话设置。点击 New Chat 创建新对话，可创建文件夹分类聊天。聊天列表右侧三个点可筛选和排序。对话窗口下方加号上传文件，默认支持 RAG，一次最多 5 个文档（PDF、DOCX、TXT、CSV）。内置 RAG 不是专业 RAG 软件，只是简单文本切分检索，对回复要求高建议只把 LM Studio 当模型加载后端。右侧小锤子激活内置插件功能。右侧展示当前上下文长度。用户/助手选项切换发送信息角色。右侧编辑按钮调整输出内容，分支按钮创建分支保存点，重新生成或续写，每个回复保存在独立分支，可点箭头快速切换。

**右侧列表**：锤子选项添加内置插件，点 install 调整 MCP 配置目录，输入 MCP 标准格式导入。下方 RAG 和 JS code sandbox 是内置插件，功能更强大但不如 MCP 好部署。

**右侧配置按钮**：调整当前绘画下模型设置，包括预设、系统提示词、温度、上下文截断、采样设置、结构化输出、投机解码等，基本已汉化。

**模型下载与导入**

点击左侧第四个选项卡，内置模型市场。无显示则配置网络代理。搜索千问3 VL 4B 示例，点击模型看具体选项卡（标注是否支持视觉等）。下方 Download Options 有官方推荐，右上角 Show all options 显示所有量化等级。Q 后面数字越大，量化等级越大，性能损失越小，占用显存越大。不建议低于 Q4，尽量选 Q8 或 Q6。点击 Download 自动下载。

手动导入：点击左侧第三个选项打开模型管理页面，右下角目录是本地模型文件目录，默认在 C 盘，可调整到其他盘，**目录不能有中文字符**。打开资源管理器，新建文件夹命名任意，双击进入，再新建目录，双击进入，将 GGUF 文件放入。

**模型加载**

点击第二个选项，右上角 Load Model 选择模型，调整参数，点右下角加载模型。三个重要参数：

1. **估计显存占用量**：LM Studio 自动估算，调太大超过显存可用范围会导致严重降速甚至系统崩溃。
2. **上下文长度**：决定模型可用上下文长度。4096 token 约 3000 中文文本。超过会导致部分文本被遗忘，根据任务调整。
3. **GPU 卸载**：GGUF 模型最重要参数。GGUF 量化将模型切成多层，一部分加载到显存，超出显存承受范围的层数用 CPU 内存代偿。分配给 GPU 层数越多，运算速度越快。即使只将 1-2 层卸载到 CPU 和内存，也会因水桶效应导致输出速度大幅下降 8% 甚至 90%。有条件尽量拉满。

左下角记住模型设置，打开更多高级选项（不了解不要调整）。点击加载模型，左上角图标变 ready 即加载完成。模型支持的特殊选项（多模态输入、工具调用）以标签形式展示。

**对接外部软件**

打开模型服务，左上角 Status 勾选。LM Studio 支持三种端点：自家 API、OpenAI 标准格式接口、Anthropic 标准格式接口。Server Settings 调整端口号、是否健全、激活的 API Key、是否局域网提供服务、是否允许 MCP 等。

**对接 Cherry Studio**：左下角设置 → 模型服务 → 找到 Cherry Studio 内置的 LM Studio 接口 → 复制 LM Studio 右上角地址粘贴到 API 地址。若 Server Settings 开了要求健全，需在 LM Studio 打开 Manage Tokens → Create New Tokens，设名称，调整 MCP 选项，Create，复制 API Key 粘贴到 Cherry Studio。点击左下角管理选项，看到 LM Studio 所有可用模型，点右侧加号添加。

**对接 AI Translator**（2.3 或 2.2 版本）：点击下方模型加载 → 选择 OpenAI 接口 → 复制 LM Studio 右上角地址，末尾加 `/v1`。复制 LM Studio Server Settings 密钥。模型选项复制 LM Studio 显示的模型名称（如千问3 VL 4B），粘贴进去，额外参数默认，保存。

**对接 Luna Translator**：启动后点击设置 → 翻译设置 → 大模型通用接口右侧设置 → 复制 LM Studio 地址，需加 `/v1`。API Key 复制进去。模型点刷新看到所有可用模型，选择需要使用的，其余默认。打开大模型通用翻译接口，用剪贴板翻译测试。

LM Studio 支持加载 EMB 模型（GGUF 格式即可）。

**关于本地 AI 与 LM Studio 使用的分析**

**云端 AI vs 本地 AI**

ChatGPT、Claude 都是云端 AI：你的问题会离开电脑，穿过互联网跑到他们服务器上，处理完再传回来。就像点外卖，订单信息先传到餐厅，做好再送过来。

本地 AI 就像自己在家做饭：食材（AI 模型）已经下载到你家（电脑），厨房（内存）里加工，端上桌就能吃，全程不出门。

**好处**：隐私（数据不离开电脑，拔网线也能用）、免费（无订阅费、无 API 调用费，下载就是你的）。
**代价**：本地模型通常比云端慢，也没那么聪明——自己做饭可能不如米其林大厨，但方便、安全、免费。

**安装 LM Studio**

去官网 lmstudio.ai，支持 Windows、macOS、Linux。下载安装包，双击运行，一路同意下一步。

默认英文，设置 → General → 语言，选简体中文或繁体中文（中文语言包仍在开发中，不完整，菜单栏仍有大量英文）。

**下载与加载模型**

主页第一个是聊天列表，本地没模型时不可用。点击第四个选项看到搜索界面，汇集各种 AI 模型（写代码的、聊天的、看图的）。

LM Studio 贴心功能：自动检测电脑配置并推荐适合的模型。模型太大跑不动会直接警告“可能太大无法运行”或“可能能部分加载进 GPU 显存”，省去查参数量量化精度的时间。

下载 Gemma 4 E2B（约 4GB，什么电脑都能跑），点“在聊天中使用”，点“加载模型”。

**概念**：模型下载存在硬盘上像文件存在文件夹里，要用得先加载到内存里。像请电工上门，还没干活先付 150 块上门费。模型加载到内存先占 4.4GB。

测试：输入“你好”，它先输出思考过程，2.92 秒后回复。生成速度 60+ token/秒。上传猫咪沙滩照片问看到什么，回复“一只猫在沙滩上休息”，速度 80 token/秒。上传 PDF 问讲了什么，正确描述云盘资源搜索界面。

**Playwright MCP（浏览器自动化）**

微软出的浏览器自动化工具，给本地 AI 增加操作浏览器能力。去 GitHub 主页找 LM Studio 选项，点 Add to LM Studio。新聊天窗口默认不打开，需手动开启工具。

测试：问“我的博客网站置顶文章里面讲了什么”，它通过 Playwright MCP 访问网站，拿到置顶两篇文章信息，与博客首页描述完全一致。小模型执行复杂任务可能翻车，卡住不知道下一步，越大越聪明能处理复杂情况、失败自己重试。

**注意**：每装一个 MCP 插件额外占用上下文空间，不要装太多，够用就行。

**LM Link（多设备）**

多台电脑时，一台性能强的跑模型，另一台远程使用。如 MacBook Pro 加载 16GB Gemma 4 26B 模型，Windows 通过 LM Link 连接过去。需注册账号。

**开发者模式（连接外部工具）**

LM Studio 开发者标签页有本地服务器面板，在电脑上开一个本地 API 地址（像 ChatGPT 云端有 URL，LM Studio 本地也有 URL）。复制本地 URL 粘贴到想接入的工具。

接入 Claude Code：打开配置文件，找到 API 配置，粘贴 LM Studio URL，填模型名称，保存重启。打开 Claude Code 模型选择，看到 LM Studio 里加载的模型。也可用 CC switch 管理并连接 LM Studio 本地模型服务，实现一键切换。

同样方法可接入各种自动化工具、编程 IDE、自己的应用——只要支持 OpenAI 兼容 API 格式。

MCP 插件生态丰富：操作项目管理工具、查询数据库、控制智能家居。去对应工具官网或 GitHub 主页搜“工具名 + MCP”。

**本地模型选择建议**

- 内存不足 16GB：从 Gemma 4 E2B 开始（约 4GB，什么电脑都能跑），适合入门体验
- 16GB-32GB 内存：试 Gemma 4 E4B 或同级别模型，效果更好
- 32GB 以上内存或独立显卡：上 Gemma 4 26B，能处理复杂任务（多步推理、代码生成、长文档分析）

原则：先从小开始试，不够用再换大的。不要一上来下载几十 GB 大模型，结果电脑跑不动。

**总结**

1. LM Studio 是完全免费的桌面工具，让你在本地电脑运行 AI 模型，数据永远不离开电脑。
2. 通过 MCP 插件给本地 AI 扩展各种能力（浏览器自动化、项目管理等），生态丰富。
3. 通过开发者模式把本地模型连接到 Claude Code、编程工具、自动化平台，成为工作流一部分。
