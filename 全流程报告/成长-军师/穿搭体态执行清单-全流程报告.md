# 体态与穿搭执行清单

> 版本 v1.0 ｜ 2026-10-10 ｜ 军师执行层文件
> 数据基础：168cm / 65kg / 肩宽 45 / 头宽 17 / 裆底 73 / 腰围 84 / 鞋码 41 / 暖皮
> 目标：**不是减重，是显高、显精神、显头小。**

---

## 〇、优先级判断（先看这个）

```
体态矫正（★★★★★）> 穿搭选型（★★★★）> 增肌撑肩（★★★）> 减脂（★★）
```

原因：168cm 的身高，**体态决定视觉高度**。圆肩驼背会让你看起来矮 3-5cm 且没精神。
体重 65kg 对 168cm 是正常范围，**不需要减重**。腰围 84 偏大，靠体态和穿搭缓解即可。

## 一、体态矫正计划（最高优先级）

### 1.1 三个必须解决的问题

| 问题 | 自测方法 | 影响 |
|---|---|---|
| **圆肩驼背** | 靠墙站，后脑/肩胛/臀能否同时贴墙 | 显矮、显垮、显没自信 |
| **颈椎前倾** | 侧面照，耳垂是否在肩峰前方 | 显猥琐、显疲惫（久坐改代码高发） |
| **骨盆前倾/后倾** | 侧面照，腰是否过度前凸或塌平 | 影响腰线与腿长视觉 |

### 1.2 每日 15 分钟矫正动作（无需器械）

**晨起或睡前各做一轮：**

| 动作 | 组数 | 作用 |
|---|---|---|
| 靠墙天使（Wall Angel） | 3×10 | 开胸、改善圆肩 |
| 门框拉伸（胸大肌） | 每侧 30 秒 ×3 | 松解紧张胸部 |
| 下巴回收（Chin Tuck） | 3×15 | 矫正颈椎前倾 |
| 猫牛式 | 2×10 | 脊柱灵活性 |
| 臀桥 | 3×15 | 激活臀部，改善骨盆前倾 |
| 死虫式（Dead Bug） | 3×10 | 核心稳定，收腹 |

**关键习惯（比动作更重要）：**
- 电脑屏幕垫高到**视线水平**（这是颈椎前倾的根源）
- 椅子有腰靠，坐时**肩胛后收下沉**
- 手机举到眼前，别低头看
- 走路时**想象头顶有根线往上拉**

**验收标准**：连续做 3 个月，拍侧面照对比，耳垂应回到肩峰正上方。

### 1.3 增肌优先级（撑肩缩头）

你的肩宽 45cm 是**优势，别浪费**。增肌能直接改善头肩比（视觉缩头）。

| 部位 | 动作 | 频率 |
|---|---|---|
| **三角肌中束**（最优先·撑肩） | 侧平举 | 每周 2-3 次 |
| 背阔肌（拉宽背） | 引体向上 / 高位下拉 | 每周 2 次 |
| 胸大肌（平衡前侧） | 俯卧撑 / 卧推 | 每周 2 次 |
| 核心（收腰） | 平板支撑、悬垂举腿 | 每周 3 次 |

预算提示（中等预算档）：健身卡 + 一副哑铃（居家）即可起步，不需要私教。

## 二、穿搭执行体系

### 2.1 三个视觉目标的实现路径

| 目标 | 底层原理 | 手段 |
|---|---|---|
| **显头小** | 增加肩宽视觉 / 缩小头部视觉 | 有肩线版型、垫肩结构、两侧短发 |
| **显腿长** | 提高腰线 | **必须扎衣服**、中高腰、同色系延伸 |
| **显精神** | 线条干净、比例协调 | 合身 > 宽松，肩线对齐，裤长精准 |

### 2.2 上衣规则

| 项 | 要 | 不要 |
|---|---|---|
| 版型 | 有肩线、微修身、衣长不过胯 | 落肩、oversize（放大头）、紧身 |
| 领口 | 小立领、V 领、开领、有领衬衫 | 高圆领、紧领、堆堆领 |
| 穿法 | **一定塞进裤腰**（拉腰线） | 直筒罩在外面 |
| 材质 | 有筋骨的（挺括棉、毛呢） | 软塌贴身的（显肉） |
| 图案 | 纯色、细竖条纹 | 大图案、横条纹、logo 轰炸 |

### 2.3 裤子规则（腰围 84 的约束）

| 项 | 要 | 不要 |
|---|---|---|
| 腰型 | **中高腰**（前提是上衣扎进去） | 低腰（显腿短） |
| 版型 | 直筒 / 微锥（Slim Straight） | 紧身、阔腿 |
| 腰围 | 坐下不勒为准，宁松勿紧 | 勒出痕 |
| 裤长 | 盖到鞋面 1/3，不堆脚背 | 拖地、九分露脚踝（显腿短） |
| 颜色 | 深色优先（黑、深灰、藏青、卡其） | 浅色膨胀色 |

### 2.4 鞋子规则

- 41 码；**厚底/坡底运动鞋或切尔西靴**，隐形增高 2-3cm
- 避免：尖头薄底皮鞋（显脚长显矮）、过于笨重的老爹鞋（显腿短）
- 鞋裤同色系 → 视觉延伸腿长

### 2.5 配色方案（暖皮专用）

**你的色板（暖调）：**
```
主色：米白 · 燕麦 · 驼色 · 卡其 · 咖色 · 橄榄绿
点缀：砖红 · 焦糖 · 深橙（小面积）
基础：深灰 · 藏青 · 黑（作为压色）
```

**避雷色**：荧光色、冷调粉紫、正冷白（显气色差）、大面积纯正红（抢脸）

### 2.6 发型的处理（油转干后需调整）

- 目标：**两侧打薄、顶部留高度**（拉长脸型 + 缩头）
- 发量多可做层次，避免蓬松两侧
- ⚠️ 用药后头发由油转干 → **需要加保湿**（换用滋润型洗发水，减少洗头频率）
- 保持干净是底线，你的自律没问题，这条不难

### 2.7 眼镜（可保留）

现有"墨黑绿上半框 + 银下细边"已有缩脸效果，**建议保留**。
若换：镜框宽度不超过脸最宽处，避免小圆框（显脸大）和大方框（压脸）。
