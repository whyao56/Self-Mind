# 模板

这页放能直接套着用的东西：方法论、校验脚本，以后新建笔记要用的模板也放这。
跟三区的关系：仓库区是沉下去的内容，工作区是在办的事，模板是拿来用的工具。

## 方法论文档

两份，按要不要动手分：

- [[内容优化方法论-概括版]]，决定一篇笔记怎么处理，看这页就够
- [[内容优化方法论-详尽版]]，要照着做，或者查某个环节的具体标准，看这份

概括版是决策卡，详尽版是操作手册。两份都写了什么时候别用，也各带一个真跑过的例子。

- 概括版的例子是查型：`仓库区/知识/军事与战争/FPV无人机视角下的战场.md`
- 详尽版的例子是做型：`仓库区/手艺/浏览器与网络/油猴插件.md`，七步全走了一遍，校验输出是真的

为什么按「将来怎么被调用」分型，推导过程在 [[内容分型优化方法论-全流程报告]]。
能直接复制的批量提示词在 [[笔记内容优化-提示词包]]。

## 脚本

- `模板/verify_append.py`，追加块校验。看我加的块有没有弄丢原来的标签、BV 号、图片引用，顺带查有没有混进元叙述和层级前缀

用法：

```
python 模板/verify_append.py <原文件> <写入后的文件>
```

这个脚本拿正反两个例子试过，该过的过，该报错的报错。
有个坑记一下：全库有 39 篇笔记的 Tags 行折成两行，脚本得把续行一起读进去，不然这些笔记的标签会漏检。
