**关于双显示器设置的操作整理**

**前提**：保证显卡驱动正常。

**第一步：设置主显示器**

右键桌面 → 显示设置。打开应用时窗口显示在哪台显示器上，说明那台是主显示器。想改变主显示器，点击对应的显示器编号（如“1”或“2”）→ 在多显示器里点击“视为主显示器”。应用窗口就会跑到新设置的主显示器上。根据习惯设置哪台是主显示器，哪台是扩展显示器。

**第二步：对齐显示器高度**

两台显示器高度不一样时，如果设置为相同水平线，鼠标穿过两台显示器时会一个在偏上、一个在偏下，操作上感觉不好。需要把其中一台调高一点，让比例差不多，点击应用。反复调整到基本在一个水平位置，实现无感切换。

**第三步：多显示器使用**

可以边浏览网页边看抖音，或边办公边聊微信，把窗口拖到对应显示器即可。

**第四步：竖屏设置**

右键 → 显示设置 → 把显示器方向设置成“纵向” → 保留更改。如果方向反了，选择“纵向翻转”。竖屏看抖音比较舒服。设置完后还需要调整显示器位置（箭头对齐），把底部差不多对齐，点应用，鼠标箭头基本无感切换。

**关于竖屏显示器及双屏摆放方式的操作整理**

**竖屏显示器：看视频、做表格方便**

操作：用影音线连接主机显卡和显示器插口 → 按 `Win+P` 投影方式选“扩展” → 鼠标右键桌面点击“显示设置” → 把副显示器的显示方向选择“纵向” → 把两台显示器对齐排列。这样看视频、做表格就很方便。

**双横屏：直接对齐排列。**

**其他摆放方式：**

- 并排横竖
- 上下横屏摆放

怎么摆都行。
