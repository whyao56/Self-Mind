一篇军事战术汇总，整理了三十多种战术的核心逻辑：

- **狙击陷阱**：故意打伤敌军，引更多人来救，再一并消灭。

![[仓库区/图片、附件/Pasted image 20260827165705.png]]

- **齐射**：所有火炮同时发射第一发，打猝不及防。舰船水战适用。

![[仓库区/图片、附件/Pasted image 20260827165652.png]]

- **低姿态阵地**：坦克藏在山坡背面，只露炮管，适合有俯角的地形。

![[仓库区/图片、附件/Pasted image 20260827165918.png]]

![[仓库区/图片、附件/Pasted image 20260827165946.png]]

![[仓库区/图片、附件/Pasted image 20260827170000.png]]

![[仓库区/图片、附件/Pasted image 20260827170031.png]]

- **蠕动弹幕**：炮火逐步前推，跟着步兵前进作掩护。需要步炮紧密协同，风险高。

![[仓库区/图片、附件/Pasted image 20260827170115.png]]

- **闪电战**：集中装甲和摩托化部队呈箭头突破防线，不断改变前线让敌人失衡。德军二战招牌。

![[仓库区/图片、附件/Pasted image 20260827170208.png]]

![[仓库区/图片、附件/Pasted image 20260827170232.png]]

- **散兵坑**：两人步兵掩体，伪装好。日本版只能塞一个人，更适合伏击。

![[仓库区/图片、附件/Pasted image 20260827170302.png]]

![[仓库区/图片、附件/Pasted image 20260827170325.png]]

- **火力侦查**：朝可疑位置开枪，看敌人是否还击来确认位置。

![[仓库区/图片、附件/Pasted image 20260827171054.png]]

![[仓库区/图片、附件/Pasted image 20260827171106.png]]

- **单翼包围**：正面佯攻，另一支部队从侧翼绕后断补给和通讯。

![[仓库区/图片、附件/Pasted image 20260827171133.png]]

- **钳形攻势**：中央牵制，两翼从两侧包抄，形成合围。

![[仓库区/图片、附件/Pasted image 20260827171201.png]]

- **斜线阵**：兵力集中在一侧，以斜线推进，在一点上突破。

![[仓库区/图片、附件/Pasted image 20260827171239.png]]

- **佯退**：假装撤退诱敌深入，纪律差的部队容易弄假成真。

![[仓库区/图片、附件/Pasted image 20260827172039.png]]

![[仓库区/图片、附件/Pasted image 20260827172053.png]]

- **倒楔形**：中央故意后退诱敌深入，两翼前推包抄。

![[仓库区/图片、附件/Pasted image 20260827172126.png]]

![[仓库区/图片、附件/Pasted image 20260827172139.png]]

- **十字交火**：舰船横穿敌舰队前方，横向船只全员开火，纵向船只只能用前炮。

![[仓库区/图片、附件/Pasted image 20260827174444.png]]

![[仓库区/图片、附件/Pasted image 20260827174457.png]]

- **交替掩护**：分两组，一组开火压制，一组前进；交替掩护推进。

![[仓库区/图片、附件/Pasted image 20260827174527.png]]

![[仓库区/图片、附件/Pasted image 20260827174600.png]]

- **埋伏**：隐蔽部队趁有利时机发起突袭。

![[仓库区/图片、附件/Pasted image 20260827174637.png]]

- **游击伞兵**：小股分散部队在前方袭扰，拖延、消耗敌人。

![[仓库区/图片、附件/Pasted image 20260827174714.png]]

![[仓库区/图片、附件/Pasted image 20260827174726.png]]

- **袭击战壕**：夜间摸哨，无声击杀守军，再向掩体扔手榴弹。常用来抓舌头、摧毁装备、搞情报。

![[仓库区/图片、附件/Pasted image 20260827174801.png]]

- **蜂拥战术**：多个单位从不同方向同时攻击同一目标，迷惑敌人。不对称战争中常用。

![[仓库区/图片、附件/Pasted image 20260827174837.png]]

- **楔形阵**：三角形阵型，古代近战常用。现代警察防暴队也用，视野好。

![[仓库区/图片、附件/Pasted image 20260827174906.png]]

![[仓库区/图片、附件/Pasted image 20260827174917.png]]

- **逐个击破**：分兵诱使敌人分散，再集中优势兵力逐一吃掉。

![[仓库区/图片、附件/Pasted image 20260827174946.png]]

- **空中封锁**：轰炸不直接威胁当下但影响后续的战略节点。分战术封锁（前线补给）和战略封锁（桥梁、公路）。

![[仓库区/图片、附件/Pasted image 20260827175016.png]]

- **围攻**：围城断补给，逼敌人投降或发动总攻。反围攻线防城外援军，围困线防城内突围。

 ![[仓库区/图片、附件/Pasted image 20260827175049.png]]

- **穿墙战术**：城市战中从建筑物内部穿墙推进，避开暴露的街道。

![[仓库区/图片、附件/Pasted image 20260827175137.png]]

![[仓库区/图片、附件/Pasted image 20260827175123.png]]

- **空袭**：直升机运步兵到敌后，形成垂直包围。

![[仓库区/图片、附件/Pasted image 20260827175156.png]]

- **坦克步兵协同**：步兵坐坦克前进，最后阶段下车作战，同时保护坦克不被反坦克武器攻击。

![[仓库区/图片、附件/Pasted image 20260827175223.png]]

- **打了就跑**：炮兵开火后立刻转移阵地，防反击。

![[仓库区/图片、附件/Pasted image 20260827175241.png]]

![[仓库区/图片、附件/Pasted image 20260827175259.png]]

- **行进射击**：步兵边前进边射击，压制敌人使其躲藏，目的是逼近打近战。

![[仓库区/图片、附件/Pasted image 20260827175322.png]]

- **中央剥皮**：小股步兵撤退时交替掩护脱离接触。

![[仓库区/图片、附件/Pasted image 20260827175359.png]]

![[仓库区/图片、附件/Pasted image 20260827175413.png]]

- **纵深防御**：不硬挡进攻者，用空间换时间，等敌人被拉长后再反击。

![[仓库区/图片、附件/Pasted image 20260827175433.png]]

- **焦土政策**：撤退时烧毁一切可能被敌人利用的资源。

![[仓库区/图片、附件/Pasted image 20260827175501.png]]
