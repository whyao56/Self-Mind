**关于安全有效清理 C 盘的方法整理**

C 盘爆红别急着用清理大师，也别乱用教程（有些操作会导致电脑瘫痪）。以下是安全有效的清理方法。

**第一步：清理临时文件**

`Win+R` 打开运行框，输入 `%TEMP%`，回车。弹出文件夹里全是临时缓存文件，`Ctrl+A` 全选，`Shift+Delete` 永久删除，确认。这些缓存是系统和软件运行时生成的临时数据，删掉不影响电脑运行。

**第二步：磁盘清理工具**

`Win+S` 搜索“磁盘清理”，打开后选 C 盘，等扫描完成，点击“清理系统文件”，再选 C 盘。出现选项后能勾的全勾上，确定删除。这些是 Windows 更新残留、缩略图、缓存等，放心删。

**第三步：清理临时文件并开启存储感知**

`Win+I` 打开设置，搜索“存储感知”。可看到存储空间被哪些大文件占用，删除没用的大文件和应用。临时文件占用可全选清理（下载文件、Windows更新日志、英特尔临时文件等）。回到存储感知页面，打开按钮并设置成每天自动清理，以后系统自动打扫垃圾文件。

**进阶设置**

**1. 不要移动桌面位置。** 有些博主教你把桌面文件夹转到 D 盘或 E 盘，容易导致系统错误，甚至需要改注册表恢复，很危险。

**2. 关掉休眠功能。** 休眠会在 C 盘生成一个和内存容量差不多大小的文件。`Win+Q` 搜索 CMD，右键“以管理员身份运行”，输入关闭休眠的命令回车。想恢复把 off 改成 on 即可。内存大的电脑这个文件可能占十几个 G，平时用不到休眠就直接关掉释放空间。

**3. 软件缓存转移。** 很多软件默认把缓存存 C 盘。比如微信：设置 → 文件管理 → 把保存路径改到别的盘符。剪辑软件、浏览器缓存同理改到 D 盘或 E 盘。长期运行缓存越积越多，动不动几十个 G，挪走 C 盘就能保持干净。
