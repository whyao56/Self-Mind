**关于解压压缩包的完整操作整理**

**第一步：认出压缩包**

桌面上的三个文件：
- `.zip` → ZIP 压缩包
- `.7z` → 7Z 压缩包
- `.rar` → RAR 压缩包

这三个都是压缩包，用压缩软件打开。

**第二步：下载安装 7-Zip**

浏览器双击打开，输入 `7-zip` 回车，找到 `7-zip.org` 这个网站，点进去。找到第一个带下载标识的链接点它，稍等下载完成。点开安装程序，允许 → 是 → 是，点 Install，点 Close，再点一下关闭。浏览器可以关掉了。

**第三步：以管理员身份运行**

开始菜单 → 所有应用 → 找到 `7-Zip` → 右键 `7-Zip File Manager` → 更多 → 以管理员身份运行 → 是。

**第四步：关联文件类型**

点“工具” → “选项” → 把两个加号都点一下 → 点击“应用” → 确定 → 关闭。桌面上三个压缩包就都能打开了。

**第五步：解压**

右键压缩包 → 显示更多选项 → 点 `7-Zip` → 点“提取文件” → 不知道路径就不要改，知道可以改 → 点确定。文件夹就解压出来了，可以点开使用。
