# 内容优化方法论 · 概括版

> 一页看懂。决定「这篇该怎么处理」的时候看它，不用看详尽版。
> 详尽版：[[内容优化方法论-详尽版]]　完整推导：[[内容分型优化方法论-全流程报告]]

---

## 适用条件

### 该用

- 手上有一批**自己写的**笔记，想提升「将来还能不能被用上」
- 笔记已经有正文了（不是空壳、不是只有链接）
- 允许先跑 9–12 篇样板，格式定了再全量

### 不该用

- **笔记还没成形** → 先记，别优化。空壳优化完还是空壳
- **索引页 / 军师台账** → 那是生成物，只维护。优化它们等于破坏它们
- **想调整主题分类** → 那是归类问题，不是优化问题
- **内容只有一句话没有观点** → 优化无从下手，标「不足」跳过

### 边界一句话

只要这篇笔记将来会被**查 / 做 / 想 / 练**其中一种方式调用，就适用；如果它永远只是"存着"，不适用。

---

## 一句话原理

> **优化不按主题分，按「这篇将来怎么被调用」分。**

同一篇讲「睡眠」的内容：用来**查**就该压成结论；用来**做**（怎么改善睡眠环境）就该写成可执行步骤。主题一样，处理方式完全不同。

信息只有被调用才算资产——这是「光记不是目的」的落地方式。

## 四型速查

| 型 | 对象 | 篇数 | 追加什么 |
|---|---|---|---|
| **查** | `仓库区/知识/` | 300 | 结论 + 场景 + 补漏 |
| **做** | `仓库区/手艺/` | 87 | 解决什么 + 前置条件 + 失效风险 + 验证状态 |
| **想** | `日志`·`旧日志`·随笔 | 18 | 深度整合（逐日推进，已有做法） |
| **练** | 书·语言·提示词 | 20 | 问题 + 答案要点 + 记忆锚点 |
| — | 军师台账 + 31 索引 | 33 | **只维护，不优化** |

**顺序**：做 87 → 查 300 → 想 18 → 报告 37 → 练 20。先做「做」型，因为最少、最值钱（教程过期就是真返工）。

## 追加块模板（直接复制）

统一输出格式，`@@@` 分隔每条，方便程序解析：

**查**

```
@@@ <文件名>
结论：<一句话陈述句，脱离原视频也能读懂>
场景：<当我在做 X 的时候> / <场景2>
补漏：<补法 或 无>
@@@
```

**做**

```
@@@ <文件名>
解决什么：<一句话>
前置条件：<软件版本/账号/权限/系统环境；原文没写就写「原文未写」>
失效风险：<最可能随时间失效的点，至少 1 条>
验证状态：<已验证 <日期> / 未验证>
@@@
```

**练**

```
@@@ <文件名>
问题：<能用来考自己的问题>
答案要点：<3 句以内>
锚点：<一个画面/比喻/例句>
@@@
```

写法要点：**只输出追加块，不重写原文**。追加块贴在笔记末尾，原文一个字不动。

## 流水线（7 步）

1. **分批** — 每批 10 篇，按领域切，不跨领域混批
2. **选提示词** — 一次只跑一种类型（提示词见 [[笔记内容优化-提示词包]]）
3. **出追加块** — 模型只输出结构化块
4. **校验** — 脚本比对：原标签种类 / BV 号 / 图片引用，三项 0 丢失
5. **追加** — 写入笔记末尾，frontmatter 加 `整理: <日期>`（幂等）
6. **抽检** — 每批人看 2 篇，跑偏就停
7. **提交** — 每批一次 git commit

---

## 红线（哪一型都别踩）

1. 不改原文，只追加
2. 不写元叙述（"这条笔记是为了…""将来我失忆了…"）
3. 不加层级前缀（写 `#以物传情`，不写 `#内核/以物传情`）
4. 每批必校验（标签 / BV / 图片引用 0 丢失）
5. 每批必提交（一次 commit，坏了好回退）
6. 不碰状态文件（台账与索引只读）

## 演示实例 · 查型

**原笔记**：`仓库区/知识/军事与战争/FPV无人机视角下的战场.md`（原文 300 字，讲两个士兵遇上 FPV 无人机的瞬间）

**提示词**：通用约束 + 查型提示词 + 该篇正文

**模型输出（追加块）**

```
@@@ 仓库区/知识/军事与战争/FPV无人机视角下的战场.md
结论：真正的绝望不是喊叫，是身体先反应、表情还没来得及跟上。
场景：写人物濒死的段落 / 分辨「表演性恐惧」和真实恐惧 / 分析战场影像
补漏：FPV 是「穿越机」第一人称视角，画面抖动大、速度快——最后那帧定格是偶然拍到的，不是刻意给的特写。
@@@
```

**追加后的笔记末尾**

```
原来人在绝望时，真的会嘴角上扬。

Tags: #FPV无人机 #战争 #绝望 #人性 #瞬间

> 结论：真正的绝望不是喊叫，是身体先反应、表情还没来得及跟上。
> 场景：写人物濒死的段落 / 分辨「表演性恐惧」和真实恐惧 / 分析战场影像
> 补漏：FPV 是「穿越机」第一人称视角，画面抖动大、速度快——最后那帧定格
>       是偶然拍到的，不是刻意给的特写。
```

**效果**：原文 300 字 → 将来只需读 3 行。**原文零改动。**
