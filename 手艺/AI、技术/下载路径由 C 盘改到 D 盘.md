**关于把电脑下载路径由 C 盘改到 D 盘的操作整理**

电脑下载的软件都跑到 C 盘，用不了多久 C 盘就会爆满爆红。两步搞定默认保存位置到 D 盘。

**第一步：更改新内容的保存位置**

单击开始菜单 → 设置 → 点击左上方“系统” → 左侧栏点击“存储” → 右边点击“更改新内容的保存位置” → 把默认 C 盘全部更改成 D 盘 → 全部点击“应用”。

**第二步：更改浏览器下载位置**

打开浏览器 → 点击右上角三个点 → 下拉点击“设置” → 左侧栏点击“下载” → 更改下载保存的位置到 D 盘。
