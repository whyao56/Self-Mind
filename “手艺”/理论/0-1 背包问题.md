**关于 0/1 背包问题的分析**

一个承重 9 公斤的背包和一组物品，每件物品有重量和价值，目标是选择能最大化价值的物品，同时总重不超背包容量。

**0/1 的含义**

要么整个取，要么不取，每个物品只能取一次，不能取物品的一部分。这与部分背包问题不同——部分背包允许取物品的一部分（贪心系列教程有讲）。

**另一种解法：暴力穷举**

对每件物品择取或跳过，然后对第二个物品重复，直到遍历所有组合，时间复杂度指数增长，较大输入会 TLE。

**动态规划优化**

以两个物品、背包容量 7 为例，采用自底向上的方法。先构造一张表，列表是背包容量，行表是物品，表中每个格子存放最大价值。

**二维 DP 填表**

基于初始容量和初始无物品，第一行和第一列表示没有物品，值为零。从第一件物品开始逐行填表。

第一件物品重量 3、价值 50：
- 容量 1、2：重量超出不能放，值为零
- 容量 3：可以选不放（继承上方结果）或放进去（获得额外价值）。前半部分 DP 表示不放这些物品，直接继承上方最优解；后半部分 DP+50 表示放入当前物品，剩余容量 3-3=0，对应上方第零列的结果，在那个剩余容量下已经求出最优值，加上这件物品的价值 50，比较两种方案取更大的就是当前格子的最优结果。

逐一遍历所有物品和背包容量，直到最后一个物品表格生成，最后一格即最大价值。

**二维到一维优化**

状态转移方程：每一层代表一个物品的选择状态，每一层依赖上一层的结果，表示是否选择当前物品。

优化后的一维状态转移方程：**必须从后往前遍历重量，避免同一物品被重复计算。** 这样就从二维 DP 优化成了一维 DP，节省了空间。

**一维实现**

定义一个一维数组 `dp`，表示容量从 0 到 W 的最优价值，初始时全部设为零（还没有放任何物品）。

外层循环 `i` 遍历每一个物品，内层循环从大到小遍历容量 `j`，确保每个物品只被计算一次。

在每个位置比较两种情况：
- 不放当前物品：对应 `dp[j]`
- 放入当前物品：对应 `dp[j-w[i]] + v[i]`

取两者的最大值更新到 `dp[j]` 中。因为从后往前遍历，所以不会重复使用同一物品。

最后输出 `dp[W]`，这就是背包容量为 W 时能得到的最大价值。
