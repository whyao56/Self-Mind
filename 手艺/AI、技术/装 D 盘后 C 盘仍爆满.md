**关于软件装 D 盘后 C 盘仍会爆满的解决办法**

软件安装到 D 盘，不代表软件的所有文件都在 D 盘——缓存和临时文件的默认位置还在 C 盘。

**一、移动“我的文档”默认路径**

很多软件的临时文件会放在“我的文档”中，比如微信、QQ。

操作：打开“此电脑” → 左侧找到“我的文档” → 右键“属性” → “位置” → 直接把 C 改成 D，也可点“移动”自己指定位置。

如果桌面经常存文件，桌面也用同样方法设置。

**二、单独设置软件临时文件位置**

有些软件的临时文件不在“我的文档”，需要单独设置。比如剪映的草稿和素材默认在 C 盘其他位置，需要单独设置到其他磁盘。

经常用到的软件，快去修改设置中的临时文件位置。
