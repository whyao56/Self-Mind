**日志：**

**关于以撒忏悔龙安装与汉化兼容的教程整理**

忏悔龙（External Item Descriptions 相关的大型 mod 加载器）11月30日更新了忏悔家版本兼容。安装忏悔龙可以玩更多更大型的以撒 mod，之前很多玩家停在忏悔版本不更新，就是因为忏悔龙只支持忏悔。现在忏悔家也能用了。

**安装步骤**

1. **前提**：需要科学上网手段，否则安装时会遇到网络问题卡住。
2. **创意工坊**：搜索忏悔龙，打开创意工坊页面，最下面有 mod 安装教程文档，点击蓝色字跳转到 GitHub 页面。
3. **下载**：下载压缩文件。
4. **新建文件夹**：在硬盘任意位置新建一个文件夹（名字最好不要有中文，数字字母都行），把下载好的压缩文件解压到这个文件夹里。**不要解压到游戏路径下**，否则可能出问题。
5. **复制启动选项**：回到教程，往下翻，复制 `-pass two` 那一段。右键以撒 → 属性 → 通用 → 启动选项，粘贴这行字。
6. **替换路径**：右键刚才创建文件夹里的启动器，复制文件地址（Win11 系统右键菜单可能不同，总之复制地址）。把启动选项前面那段换成刚才复制的地址。
7. **启动**：关掉属性，启动游戏，不再直接启动以撒，而是启动忏悔龙的启动器页面，它会自动更新和安装。没有科学上网可能会卡住。

**版本差异**

安装完成后游戏路径下多出一个忏悔龙文件夹。启动器里有**两个选项**：
- 第一个：忏悔龙版本（当前支持 1.9.7.12）
- 第二个：主游戏版本（最新 1.9.7.15）

当前忏悔龙不支持最新的 1.9.7.15，只支持 1.9.7.12。启动忏悔龙版本时，右下角显示忏悔龙，游戏是英文界面（因为不是主游戏版本）。这个独立游戏版本放在刚创建的文件夹里。

**汉化（忏悔龙版本）**

打开创意工坊，找到忏悔家用的汉化补丁，下面有中文教程：打开以下目录，把里面的东西手动复制粘贴到游戏根目录，实现手动替换。这样虽然不像自动代码注入那样可以改很多（如重绘的复活肌贴图、内置图鉴中文排版），但大部分文本还是能汉化。

具体操作：在 mod 文件夹里，找到 CN_REP（订阅后自动生成的汉化文件），复制下来，回到忏悔龙新增的文件夹，打开忏悔龙启动的游戏的语言文件，把汉化文件复制进去替换。

效果：大部分字都是中文，但部分如“一店币”、楼层文字还是英文，EID 默认英文需要自己调一下。

**汉化（主游戏版本）**

主游戏 1.9.7.15 的正常汉化：打开压缩文件，直接打开里面的自动注入，选择文件写入成功，主游戏版本就会自动注入完整版汉化补丁。这个汉化更全一点。

**两个版本互不影响**

想玩 mod 就启动忏悔龙模式，想玩最新版本就启动主游戏模式，互不影响。
