**关于 PC 端 GBA 模拟器（VBA）使用教程的整理**

**准备文件**：模拟器压缩包（约1-2MB）、游戏本体压缩包（约6MB）。游戏本体压缩包**不需要解压**，直接用模拟器打开即可。

**步骤**：

1. 解压模拟器，进入文件夹，找到 VBA 模拟器图标，双击打开。
2. 模拟器黑屏打开状态，点击“文件” → “打开”。
3. 选中游戏本体压缩包，直接打开，进入游戏。
4. 点“选项” → “手柄” → “设置” → 选“1”，配置键盘按键：
   - 方向键：上下左右
   - 按键：Z、X、A、S（自己设置）
   - Select 键：空格
   - Start 键：回车
   - 速度键：加速用
   - 截图键：游戏截图
5. 设置好点确定，进入游戏，按提示操作即可。
6. 按住速度键可加速游戏，松开恢复正常速度。

**画面优化**：选项 → 过滤 → 选择“超级”两个选项之一（普通级别马赛克严重，超级选项画面更干净清晰）。
