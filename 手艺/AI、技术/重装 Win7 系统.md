**关于小白一键重装系统的操作整理**

重装系统前，先备份好桌面及 C 盘的重要资料。需要准备两个以上的硬盘分区。

打开小白一键重装系统：

```
www.xiaobaixitong.com
```

它会自动搜索相关信息。推荐安装 Windows 旗舰版，直接选择安装器。通过全选或取消点下一步。

它会自动帮助下载需要安装的系统及相关驱动，耐心等待。之后直接点“立即重启”。

重启时使用上下键进行选择，回车确定。部署完成后，直接选择 BT。使用方向键上下选择，只选第一个系统。选择第一个，回车。

系统安装完成后，右键“个性化与分辨率”，选择一个合适的分辨率后点击确定。
