**关于 Via 浏览器 12 个隐藏功能的整理**

打开浏览器发现卡住了？其实手指下滑就能调出搜索框。以下是 Via 浏览器的隐藏功能。

**一、主页搜索**

菜单添加书签时勾选“添加到主页”，网站就出现在搜索框下面。长按可删除，点击 logo 可找回刚删除的网站。长按可添加收藏生成桌面快捷方式。下滑打开搜索，点击搜索按钮切换搜索引擎。查看网站标题可直接复制网址，点击放大按钮可编辑网址。

网址前加上这串代码即可打开网站隐藏小工具：

```
wn.run/
```

**二、搜索广告**

百度搜索常出现不相关广告。百度旗下的“简单搜索”没有广告。在浏览器标识设置里点右上角加号，输入标题，将以下 UA 代码复制进去，保存后选择即可去除广告：

```
Mozilla/5.0 (Linux; Android 10; K) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Mobile Safari/537.36 SearchCraft/3.10.1 ChatSearch/1.0 SearchCraft/5.7.0.5 (Baidu; P1 10)
```

点击“电脑模式”切换为电脑 UI，长按可切换更多 UI。

**三、自动隐身**

在搜索按钮里点网站设定 → 所有网站 → 加号添加要隐身的网站 → 确定后选择网站找到“隐身”并打开。特定网站上会自动开启隐私模式。

**四、搜索引擎**

内置八个搜索引擎，可在设置里点加号自定义。

网盘资源搜索引擎代码（可切换阿里、百度、夸克、迅雷）：

```
https://miaosou.fun/info?searchKey=
```

在线 AI 搜索引擎代码（直达搜索结果，可追问）：

```
https://metaso.cn/?q=
```

学术论文搜索引擎代码（文章可免费获取）：

```
https://www.oalib.com/search?kw=
```

**五、广告拦截**

在广告拦截设置里点“规则订阅”，选中所有规则并点右上更新，防止失效。可设置每天自动更新。刷新网页后广告消失，视频片头广告也没了。还有“自动展开”选项。

**六、图片神器**

长按图片可直接免费下载。长按可选“以图搜图”，有十个搜索引擎可选。长按进入看图模式。图片是二维码可直接长按扫描。

**七、书签导入**

电脑端浏览器导出书签，发送到手机保存，在 Via 里选择导入书签即可一键导入。也可用“书签地球”网站下载别人打包好的书签直接导入。

**八、资源嗅探**

长按工具箱可嗅探所有资源，点击选择下载，同时可嗅探音乐资源。

**九、快捷键**

长按后退回顶部，长按添加回底部，长按主页进行搜索，长按标签新建标签页，点开标签页长按任意标签关闭所有标签页，长按标签页里加号找最近关闭的标签页。网页里长按菜单按钮刷新网页。可在操作设定里自定义每个长按对应的功能。

**十、脚本插件**

在 Greasy fork 网站搜索需要的插件，直接点击安装使用。

**十一、纯净阅读**

在操作设定里选一个按钮（如菜单按钮）设为阅读模式。看到有广告弹窗的资讯小说时，长按菜单按钮获得纯净阅读界面。可打开全屏模式上滑获得更沉浸体验。可在设置里更换阅读背景、字体大小，可选择朗读网页免费听书。

**十二、其他功能**

主页 logo、搜索框、背景可自定义。网页可选无图模式节省流量。支持页面查找功能，还可查看源码。
