**关于傅里叶变换的完整分析**

你用笔在纸上画出的任何形状，都可以由大量正弦波叠加而成，真的是任何形状。这就是傅里叶技术和傅里叶变换背后的思想，以约瑟夫·傅里叶命名。

没有它，你就没法看视频、发语音消息，甚至没法用手机拍照。这个思想不仅支撑着 WiFi、雷达、核磁共振成像，大约一个世纪前还为大英帝国的全球海上贸易提供了动力。几十年后，它决定了人类历史上最大规模两栖登陆作战的日期。

**从热传导出发**

傅里叶说，这一切都可以从一条事实重新发现：**热量从高温区域流向低温区域。** 就这么简单。

一块热的金属贴着一块更冷的金属，温度会怎样？热量从高温流向低温，所以温度会降低。但如果它右边还贴着一块更热的金属，温差完全相同，同样多的热量又流了回来，净热流为零，温度保持不变。

关键在于：如果左边那块只是稍微冷一点，流出的热量就会少一些，温度就会上升；如果这块热的更热，温度就会上升得更快。所以问题是什么决定了温度变化的快慢？

用几何来思考：画出温度-位置图。温差相同时，图像是一条直线，斜率不变，温度不变。左边稍微冷一点，斜率增大，温度升高。左边更热，斜率增加得更快，温度升得更快。所以温度变化率直接关系到斜率变化的快慢，也就是斜率本身的变化率——斜率本身就是温度的变化率，所以我们得到了**二阶导数**，**热传导方程**就此诞生。

**热传导方程在说什么**

二阶导数意味着**曲率**。某个点的温度变化快慢取决于那个点的温度曲率：

- 如果没有曲率，温度不变
- 如果有正的向上曲率，温度上升
- 曲率越强，温度升得越快
- 如果有向下曲率，温度下降

应用：一根棒子处在室温，加热某个位置让温度出现尖峰。过一小会儿会怎样？看各处的曲率——在峰值处曲率最强，那里降温最快；越往外曲率越小；曲率降到0；接着变成向上曲率，这些地方会升温。过一小会儿温度曲线就会变成新的形状。

这个方程让我们能预测温度剖面如何随时间演化。

**为什么这个方程到处适用**

热量从高温流向低温，神经元里的电荷从高电压流向低电压——完全相同的物理规律可以用来模拟电流如何在神经元中流动。同样的方程也支配着突变如何在种群中传播，或不确定性如何在金融市场中扩散。

因为其核心现象是**扩散**，所以这个方程本质上就是一个**扩散方程**，是我们宇宙中最常见的事情之一。

**怎么解这个方程**

傅里叶用了最棒的解题技巧之一：**如果你解不出一道难题，看看能不能先解决它的一个简化版本。**

初始温度分布曲率杂乱无章，看起来很复杂。能不能从一个曲率很规整的分布开始？**正弦波**。

正弦有一个很优美的性质：**它的曲率与高度成正比。** 高度为零处曲率为零，高度最大处曲率最大，高度为最大值一半处曲率也为最大曲率的一半。

如果初始分布是正弦曲线，那么温度的变化率就会与高度成正比，每个点的温度按自身高度的比例变化。过一小会儿形状看起来一模一样，正弦只是整体缩小了。而且会永远这样持续下去。整张图只是在按指数规律收缩。

**如果初始图像有两条正弦曲线？**

它会和之前那条以同样的速度收缩吗？不是。在相同位置挤进了两条正弦波，各处的曲率都高得多，温度变化会快得多，整个图像会比之前收缩得快得多。**频率越高，收缩得越快。**

**傅里叶级数的诞生**

如果初始温度分布是两条不同频率的正弦曲线之和，结果就不再是正弦曲线，形状会看起来相当复杂。直接求解它会是一场噩梦。但我们可以把它拆回组成它的正弦曲线——我们已经确切知道每一条如何演化，高频正弦波衰减得快得多，然后重新加在一起得到最终的温度分布。

**诀窍**：我们从来不直接解复杂的曲线，而是把它拆解成组成它的正弦波，让每一个正弦波随时间演化，因为我们对它们的数学规律了如指掌，最后再把它们拼回去。

这之所以可行，是因为**导数是线性算子**：A+B 的导数等于 A 的导数加 B 的导数。

傅里叶在这一点上迈出了惊人一跃：**如果用纸笔能画出的任何曲线、任何形状，都可以通过叠加大量正弦波来拆解或构建呢？** 那样一来，热传导方程就正式解决了。

这就是**傅里叶级数**的诞生。就像棱镜把光分解成组成它的各种颜色，傅里叶断言任何形状都可以被分解成组成它的正弦曲线。这意味着我们可以把任何形状变换成一张展示那些组成频率强度的图——今天我们称这张图为**傅里叶变换**，因为我们确实是在把这张图变换到频域。

**怎么找出组成频率和高度**

假设信号与周期 T 永远重复。周期信号要容易解得多，所以从它开始。

如果一个信号在周期 T 之后不断重复，那么任何参与构成的正弦波也必须在周期 T 之后完美重复。这意味着可以有一个正好完成一个周期的正弦波，然后它会完美重复；或者两个周期，同样会完美重复；或者三个，以此类推。但不能有任何介于两者之间的，因为那些不会完美重复，不会完美对齐。还有一个零频率——像一个常数函数——它只是告诉我们整个信号相对于零点上下偏移了多少。

通过假设周期性，我们轻松找出了确切的频率成分。现在主要问题来了：怎么找出这些成分的确切高度？

**无限个未知数，无限个方程**

把形状叫做 F(t)，写成求和形式。如果你有一个未知数，需要一个方程来解它；有两个未知数，需要两个方程。这里有无限个未知数，所以需要无限个方程。

傅里叶说：求导。正弦无限可导，能一直求导，一次又一次得到无限个方程。然后同时解这无限个方程来求无限个变量。

这太荒谬了。得找个更好的办法。

**用积分**

积分基本上就是计算曲线下的面积，而且积分是线性的：这条曲线下的面积等于这块面积加这块面积加这块面积，以此类推。

但看那些正弦曲线，在一个完整周期内，它们的正负面积完全抵消，所以全都不见了。这意味着唯一剩下的就是这一块——曲线下的面积恰好等于这个矩形的面积，也就是幅值乘以宽度 T。于是写出 H₀×T 这个矩形的面积等于这条曲线下的面积，由此可以把 H₀ 单独解出来：**H₀ 等于曲线下的面积除以 T。**

**怎么求 H₁、H₂、H₃**

对整个等式做某种运算，使得计算面积时只有 H₁ 留下来，其他全部抵消掉。

对 H₁ 来说，面积有正有负会相互抵消。想让面积全是正的。平方？平方之后它就变成正的了，会得到正的面积。但平方所有东西都会被平方，所有东西都会变成正的，什么都不会抵消掉。而且平方不是线性的，那又是一个额外的问题。

所以需要的是某种运算，它只把这个平方（但不把其余的平方），而且它还得是线性的。

傅里叶说：**只要把整个等式乘以正弦就行。** 这样做的时候，这个被平方了，但其余没有被平方，而且乘以正弦是线性的。因为这个被平方了，它现在就会得到一个正的面积。

其余的会相互抵消吗？看乘积：如果两者符号相同，乘积就是正的，面积也是正的；如果符号相反，乘积就是负的，曲线下的面积最终也会变成负的。在正半周期内两者符号相同，得到正的面积；但在负半周期内，负成正乘积变成负的，得到相等的负面积，所以这一次它们抵消了。同样的道理到处都是，所以确实这些全都抵消了，只剩下 H₁。

现在需要求这条曲线下的面积——其实超级简单。需要求出这个矩形的面积，也就是幅值乘以半个周期。所以 **H₁×T/2 应该等于这个面积**——不是 F(t) 下方的面积，而是 F(t) 乘以正弦之后的面积。

对 H₂ 做同样的事，把整个波形乘以对应的那一条正弦曲线，然后计算面积。会发现这个面积保持为正，而其他部分全都抵消掉了。

**为什么能行**

当你把两条正弦曲线相乘，如果它们频率匹配、完全对齐，就会得到曲线下方一个正的面积。但如果它们的频率不匹配，它们就不会完全对齐，会时而对齐时而不对齐。而当这种情况发生时，一个完整周期内的曲线下方面积就会是 0。

这就是你如何把每一个正弦频率当做探针来计算它的强度——有点像用一个滤光片来找出你正在寻找的某种特定颜色的强度。

**相位问题**

到目前为止，假设每个分量都从这个精确的相位开始。但如果它不是这样开始的，如果图像平移了比如四分之一个周期，再乘以正弦，它们就不会对齐，会得到正面积和负面积，它们会完美抵消，使曲线下的面积为零。你可能会误以为那个频率的幅值是 0，但那是错的，它是存在的，只不过它相移了四分之一个周期。

傅里叶说：很简单，四分之一周期的相移基本上就是余弦。所以这次应该乘以余弦来计算面积，那样就会得到正确答案。

但如果不知道应该乘以正弦还是余弦？**两个都做。** 如果乘以正弦得到幅值为零，那就知道余弦算出的幅值才是真实幅值；反过来也一样。

如果它平移的不是正好 90 度？如果偏移到中间某个位置？那么正弦和余弦都会给出一些非零的结果。这时候只需要用**毕达哥拉斯定理**来得到真实的幅值——因为当你乘以正弦和余弦时，你实际上是在计算两个垂直的分量，所以用毕达哥拉斯定理来计算总幅值。如果取它们的比值就可以算出**相位角**，准确告诉你那个图像偏移了多少。

- 如果相位角是 0，就知道它偏移了 0 度，是一个完美的正弦
- 如果相位角是 90 度，就知道它偏移了四分之一个周期

所以现在通过同时计算正弦和余弦，我们掌握了全貌：既知道了各个组成波形的幅值，也知道了它们精确的相移。

**完整形态的傅里叶级数**

把它写成求和的形式，其中 n 是整数，把面积变成一个周期内的积分，把系数单独解出来，再用 n 统一表示。

**测试**

在模拟中测试一下，结果就在眼前。确实任何随机信号都可以用正弦波构建出来，哪怕是带有尖角的信号。理想情况下需要无限多个分量，但加的越多就越接近。

**非周期信号**

还留着一个没解决的问题：假设信号会永远重复，但现实世界里的信号并不会。

傅里叶说：非周期信号可以看成**周期为无穷大的周期信号**。

一旦这样做，就会发现如果周期趋于无穷大，所有幅度都会趋于 0，一切都趋于 0，整个东西就崩了。

傅里叶说：那不是缺陷，那是特性。一步一步走向无穷大，从周期 T 开始，如果把周期加倍，所有幅度都会减半（因为有个除以 T），但现在有更多频率可以挤进中间来。所以虽然幅度减半了，但分量的数量翻倍了，这正好补偿过来。再把周期加倍，同样的事情又发生一次。随着周期越来越大，每个单独的分量越来越矮，但越来越多的频率被挤了进来。而在周期趋于无穷大的极限下，单个分量的幅度缩到 0，但频率本身变成了一条平滑的连续频谱。

**傅里叶变换**

对于周期信号，得到一组离散的频率，可以把它们作为傅里叶级数加起来。但处理非周期信号时，不再有一个个可数的分量了，面对的是一整段连续的频率范围。这个离散的东西消失了，幅度和相位偏移变成了频率的函数——这就叫**傅里叶变换**，因为我们把信号变换到了频域。而这种重建不再是求和，而是积分，我们称之为**逆变换**，因为我们在往回走。

核心思想是完全一样的：傅里叶变换把任何信号分解成它的各个频率分量，而逆变换只是把它们重新加回去。

**潮汐预测**

在人类历史的大部分时间里，贸易、旅行和战争都依赖船只，而船只会受到潮汐的影响。算错潮汐可能意味着船搁浅甚至沉没。

潮汐大体上是由月亮每天造成两次高潮和两次低潮，但确切的高度和时间每天变化很大。因为月亮本身只贡献一个主要部分，还有太阳以稍微不同的周期贡献另一个部分，而月亮不断变化的距离和角度又引入了越来越多的这类分量。所以实际看到的潮汐最终是所有这些分量加在一起的结果。

这些分量的频率是已知的，来自天文学，但它们的幅度和相位取决于当地海岸线的边边角角，几乎不可能靠计算得出。

威廉·汤姆森（后来的开尔文勋爵）意识到：可以取任意地点的历史潮汐数据，用傅里叶分析方法提取主要分量，然后把这些正弦波简单延伸到未来，再把它们加回去——跟傅里叶最初解热传导方程的做法挺像的。

他和弟弟造了两台机器：一台是提取分量的积分机，另一台是把分量重新叠加起来的潮汐预测机。这两台机器跑上几个小时就能预测一整年的潮汐数据。这彻底改变了游戏规则，英国的海上贸易因此兴旺起来。

几十年后，盟军用类似的机器预测潮汐，策划了对德战法国的登陆。一个为了解决热传导方程而生的想法，最终竟帮助策划了史上最大规模的两栖登陆。

**今天的应用**

**语音消息压缩**：手机不会原样存下语音内容，因为那样会占用大量不必要的空间。它会先把语音分解成各个组成频率——傅里叶变换。很多频率，比如特别高特别低的频率，或者声音非常微弱的，人耳本来就听不到，留着也没有意义。所以可以丢掉大量无用信息，只保留要紧的那些，占用的空间就会小得多。这就是**音频压缩**。

**图像压缩**：照片基本上就是一个像素网格，可以看成一种亮度信号（二维信号）。如果原样存储会占用大量空间，不如把它分解成组成它的频率分量，去掉那些眼睛反正也察觉不到的分量，然后只存储那些重要分量的信息，占用的空间会少得多。这就是**图像压缩**。双击再次打开那张照片时，会用那些组成频率重新构建图像，看起来几乎一模一样。

同样的思路也适用于视频、从音频中去除噪声、给照片做模糊和锐化——说白了就是摆弄正确的频率分量。

**傅里叶变换用在 WiFi、核磁共振成像、雷达里**，凡是你能想到的都有它。

**物理傅里叶分析器**

就像棱镜能把光在物理上分离成组成它的颜色一样，能不能为声音造一个类似的东西？可以。

把声音播放给一排长度不同的微型振子。短的振子相当硬，只对高频有反应；长的振子很有弹性，会对较低频率有反应。根据组成这个声音的频率不同，不同的振子会开始被驱动起来。看哪些在震动就告诉我们存在哪些频率，它们震动的多强就告诉我们每个频率的强度。

**耳朵**

耳蜗是内耳的一部分，也有类似的结构。一端比较僵硬，只对高频有反应；另一端（蜗顶）相当柔软，会对低频产生响应。取决于哪些部位震动以及震动的强度，它们会被转换成电信号发送到大脑。这是让我们的大脑能够分辨声音、理解语言的最初步骤之一。

虽然我们花了不少时间才达到理解傅里叶变换的程度，但我们的身体从出生起就一直在做这件事。
