**关于新电脑开机必做的五个操作整理**

新电脑拿回来不能直接用，有几个操作要先做，可以很大程度上避免越用越卡。

**操作一：关闭通知**

右击桌面选择“显示设置” → 点击“通知和操作” → 关闭。这个完全就是给垃圾广告留后门，必须关掉。

**操作二：开启存储感知**

左边点“存储” → 打开。它可以删除不需要的临时文件，自动释放空间。

**操作三：更改存储位置**

下滑找到“更改新内容的保存位置” → 将默认保存位置全部改成 C 盘以外的其他磁盘 → 应用。有效避免 C 盘爆红。

**操作四：关闭开机启动**

返回系统设置 → 点击“应用” → 点击“启动” → 将没用的启动项全部关闭。

**操作五：关闭后台程序**

设置返回系统 → 点击“隐私” → 点击“后台应用” → 关闭。否则电脑一开机就卡得不行。

最后一句：只要不是新电脑游戏安装在 C 盘，优势在我。
