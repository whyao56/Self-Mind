**关于在电脑本地使用 DeepSeek V4 Flash 正式版的完整教程**

通过这个教程，可以调用 DeepSeek V4 Flash 官方 API 在电脑上进行日常对话，并开启 V4 Flash 最佳思考强度获取最高质量回答。虽然只是 Flash 版本，但目前能力已完全超越之前的 DeepSeek Pro。适合需要与 DeepSeek 进行高质量对话和流畅体验的用户。

**第一步：登录并充值**

1. 登录 DeepSeek 官方网站，点击右侧“API 开放平台”。
2. 登录账号（无账号先注册，用手机号注册，无论微信还是手机号注册都需手机号验证）。
3. 点击“去充值”，可选固定金额或点“自定义”最低充 1 元。支持微信和支付宝。

**第二步：申请 API Key**

1. 支付后点击左侧“API Key”，选择“创建 API Key”。
2. 随便写一个名字，点击创建，获得密钥。
3. **密钥一定要保存好**，只显示一次。忘记或点错需重新创建。

**第三步：下载 Cherry Studio**

1. 输入网址，点击下载 V1.9.12 版本，下载 Windows 标准版。
2. 下载后直接安装。
3. 打开后页面可能不同，跟着操作即可。白色刺眼可点左下角系统图标切换黑色。

**第四步：配置 API 密钥**

1. 点击左下角“设置” → “模型服务” → 选择“深度求索”。
2. 右上角**一定要打开**，否则用不了。
3. “API 密钥”处填写刚才申请的密钥。API 地址不要动。
4. “模型”处若为空，点击右边“获取模型列表” → 右上角“重新获取模型列表”刷新。
5. 把它们都打开（点击加号变成减号即打开）。关闭后模型列表里有很多模型，配置完成。

**第五步：创建助手并切换模型**

1. 左上角“助手” → “添加助手” → “默认助手”。
2. 点击上面模型的名字，搜索“DeepSeek V4”，看到深度求索下面有 **DeepSeek V4 Flash**，点击它切换。
3. V4 Flash 是正式版，官方已更新到最新版本（今天7月31号版本即正式版）。

**第六步：设置参数**

1. 点击“默认助手”，模型温度不要动，Top P 也不要动，最大工具调用次数关掉，上下文拉到最大。
2. 点击“提示词设置”，默认助手可改名字（如“DeepSeek V4 Flash 正式版”），点击空白处自动保存。
3. 提示词建议写成“不要迎合用户，你的观点要始终保持客观”，点击保存。
4. 点击关闭。

**第七步：开启最大思考强度和联网搜索**

1. 点击下面“思维链长度”，选择“穷究”。
2. 点击“网络搜索”功能，选择第一个 MCP。

**测试与话题管理**

测试对话，点击思维链可看它刚才在想什么。

新建对话：点击下面“新话题”或快捷键 Ctrl+N，左上角生成新对话窗口，可切换。

**自动生成标题设置**

如果无法自动生成缩略标题，说明没设置。设置方法：点击“设置” → “默认模型” → “快速模型”选成 DeepSeek。设置好后回到助手，随便说一句“给我写一首古风歌曲”，左上角名字自动变成“创作古风歌曲”标题。

编辑标题：右键点击“编辑话题名”可改名字。
