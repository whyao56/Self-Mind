1. [首页 | Tampermonkey](https://www.tampermonkey.net/)
2. 点击“去商店”![[仓库区/图片、附件/github汉化-01-点击“去商店”.png|611]]
3. 添加扩展插件（要提示“已经安装成功”）
4. 浏览器（edge）设置->扩展->管理扩展->开发人员模式
5. 点击“用户脚本”![[仓库区/图片、附件/github汉化-02-点击“用户脚本”.png|611]]
6. 点击“GreasyFork”![[仓库区/图片、附件/github汉化-03-点击“GreasyFork”.png]]
7. 输出搜索关键字“github 中文化”
8. 点击“安装此脚本”->“安装”


> 回到github官网刷新一下即可，相较于浏览器的全局翻译，该脚本可以很好的区分系统翻译和内容翻译


>想恢复英文显示，只需要关掉github中文化插件即可


如果上述操作都失败还是不行的：
1. 点击管理扩展程序
2. 找到油猴点击详情
3. 找到允许运行用户脚本，点击打开
4. 刷新github页面
