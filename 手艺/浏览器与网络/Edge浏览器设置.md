**关于 Edge 浏览器插件、隐藏设置与骚操作的整理**

1990年蒂姆·伯纳斯编写了人类历史上第一款浏览器。

**一、插件**

Edge 相较于 Chrome 的高不可攀，配置拓展功能对所有用户开放。打开开发人员模式后，可将插件下载到本地再上传到 Edge 浏览器。但装太多拓展可能让浏览器变卡，想只装一款办所有事，不二之选是**油猴（Tampermonkey）**。

**二、隐藏设置**

**1. 效率模式（必开）**

同样打开十个 B站，开了这个功能浏览器资源占用砍一半还多。在设置 → 系统和性能里，打开以下选项：

- 打开效率模式
- 使用效率模式改善电脑游戏体验
- 使用标签页休眠功能节约资源
- 淡出睡眠标签页

不活动的标签页进入休眠，不再浪费系统资源。

**2. 兼容模式（IE 模式）**

有些复古网站只能用 IE 打开。在设置 → 默认浏览器里，将“允许在 Internet Explorer 模式下重新加载网站”选为“允许”。重启浏览器后，碰到 only IE 的网站，在标签页右键选择用 IE 模式打开。

**3. 隐藏设置（edge://flags）**

地址栏输入 `edge://flags` 打开里世界：

- **Smooth Scrolling**：开启后页面滚动丝滑，不再有跳帧丢帧。地址：`edge://flags/#smooth-scrolling`
- **Parallel downloading**：开启后自带下载拥有多线程下载速度。地址：`edge://flags/#enable-parallel-downloading`
- **阻止视频自动播放**：防止视频自动播放。

**三、骚操作**

**1. 摘抄工具**

遇到充值弹窗，在地址栏网址前面加上 `read:` 就能启动超级摘抄模式。

**2. 装杯神器**

在想要修改的地方右键选择“检查”，再双击对应位置就可以编辑网页内容。截个图装杯还是可以的，还有不少别的用法。
