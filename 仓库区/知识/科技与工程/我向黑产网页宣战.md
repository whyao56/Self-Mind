**关于银狐木马检测插件 Virus Detector 的分析**

**一、背景：银狐木马**

银狐木马是近年来国内最活跃的远控木马之一，主要针对 Windows 用户。它通过伪造官方网站来传播，诱导用户下载伪装成正常软件的木马程序。一旦中招，攻击者可以远程控制电脑、窃取文件、监控键盘、盗取账号密码，甚至身份冒用诈骗。它的核心投放方式就是仿冒热门软件官网——安全软件、浏览器、输入法、办公套件、AI 应用。

典型钓鱼域名示例：`pc-huorong.com.cn`（仿冒火绒安全）、`deepseek-go.com`（仿冒 DeepSeek）、`qq.om`（拼写接近 qq.com）。这些钓鱼网站页面与真官网几乎一模一样，普通用户很难从视觉上分辨。

**二、插件初衷**

作者看到评论区大量网友中招，决定从源头出发预防中毒，花了一周时间 web coding 了这款浏览器插件，专门用于识别投放病毒的伪造官网，取名 **Virus Detector**。

**三、检测方法：四大特征**

**1. 域名仿冒（最核心）**

网址和官方不一样但很相似，通常添头加尾。查 whois 信息会发现域名年龄非常小——一个所谓的官方网页竟然只注册了两个月不到。具体手法包括：子串包含品牌名（如 `pc-huorong.com.cn` 包含 huorong）、域名段命中品牌关键词（如 `deepseek-go.com`）、使用廉价可疑顶级域（.xyz .top .cfd .ga 等）、编辑距离极小（如 `qq.om` 与 `qq.com` 仅差一个字符，肉眼极易漏看）。

**2. 没有 ICP 备案号**

国内合法网站必须在页面底部展示 ICP 备案号。钓鱼网站都是临时搭建的，攻击者今天注册域名、几天后就换，根本不会走备案流程，所以底部找不到备案号。但这条不适用于国外网站。

**3. 代码工程化程度低**

大部分钓鱼网页不是手搓的，而是批量克隆或 AI 生成的——DOM 结构极简（可能只有几十个 HTML 节点）、无主流框架痕迹（没有 React/Vue/jQuery）、外部资源稀少（脚本样式图片加起来不到 5 个）、大量异常 Emoji 符号。正经软件官网几乎不会有大量 emoji。

**4. 链接异常**

钓鱼页面最重要的只有下载页，不需要很多子页面，导致几个怪异现象：很多链接指向当前页面本身（爬虫只克隆了首页）、大量死链接指向不存在的子页面、不同按钮不同文字全指向同一个链接。

**四、评分体系**

基于以上特征，每一项规则都有相应计分方式，总分达到 100 分即判定为危险，触发警告。8 项检测规则如下：

- **域名仿冒检测（60分）**：5 层递进匹配，覆盖 121 个品牌
- **压缩包下载拦截（40分）**：zip/.rar/.7z 等自动取消并加分
- **ICP 备案缺失（50分）**：6 层扫描策略，覆盖 34 个省级行政区
- **链接分析（70分）**：同页链接 + 死链 + 重复链接 + 下载外链
- **代码工程化（60分）**：DOM 复杂度 + 框架检测 + 外部资源 + 符号密度
- **域名年龄评分（60分）**：Whois API S 型衰减函数，新域名更可疑
- **域名年龄减分（-20分）**：注册超 2 年的域名可抵消部分可疑分数
- **下载链接跨域（20分）**：跨域托管 + 新注册域名检测

**五、工程优化**

**可信平台白名单**：Wiki、博客、代码托管（github.io、fandom.com 等）的 UGC 平台自动跳过域名仿冒检测，避免误报用户文章为仿冒官网，覆盖 44 个平台。

**官方网站早期退出机制**：域名正常、ICP 备案号也查到，直接判定安全，不再跑后续链接分析和代码检测，减少不必要的计算开销。

**用户白名单**：学校内网等无法检测但对用户安全的域名，可在弹窗一键加入白名单，完全跳过所有检测，支持随时移除并立即恢复检测。

**触发响应**：红色徽章 + 独立警告窗口 + 下载拦截注入 + 官网一键跳转。

**六、获取与安装**

GitHub 开源地址：`github.com/Lolitide/VirusDetector`，可 git clone 或直接下载 ZIP。

**Chrome 安装**：打开 `chrome://extensions/` → 开启右上角「开发者模式」→ 点击「加载已解压的扩展程序」→ 选择 VirusDetector 目录确认。

**Edge 安装**：打开 `edge://extensions/` → 开启「开发人员模式」→ 点击「加载解压缩的扩展」→ 选择 VirusDetector 目录确认。

**七、使用方式**

安装完成后扩展自动在后台运行，无需额外操作。点击工具栏盾牌图标查看检测结果——绿色面板 = 安全，红色面板 = 危险。收到警告时自动弹出独立警告窗口，显示风险评分、推荐官网、一键跳转、关闭危险页面。弹窗底部点击「加入白名单」可完全跳过检测，图标显示蓝色对勾。调试入口：`chrome://extensions/` → Service Worker → 查看后台日志。

**关于钓鱼网站识别插件 Virus Detector 重构的分析**

将近一个月前分享过一款自研浏览器插件，通过本地规则分析网页风险，识别仿冒网站和钓鱼网站。视频发布后收到大量反馈——有人找到误报网站，有人提供钓鱼样本，有人对检测逻辑和用户体验提出改进意见。正因为这些建议，没有急着添加新功能，而是回头把整个插件重新设计了一遍。

**一、从 Demo 到重构**

初版 Virus Detector 只有基础规则检测。收到大量 Issue、评论和样本反馈后，决定推倒核心逻辑，全面重新设计。

**为什么推倒重来？** 三个问题：误报——官方网站被误判为仿冒，正常用户受影响；漏报——连字符仿冒域名被绕过，新型钓鱼手法未被覆盖；下载检测不足——只检测网页不检测下载，恶意文件可以直通用户。

**二、检测逻辑全面升级**

旧算法是单一规则匹配、黑白名单硬判断。新算法改为递进检测：域名相似度 → 结构特征分析 → 多维度交叉验证 → 风险评分加权综合评估，精确分级响应。多种检测方式综合判断，真正危险的网站更容易被识别，正常网站尽可能减少误报。

**三、下载检测 · 四层防御**

1. **网页扫描**：实时分析页面 DOM 与脚本，识别可疑下载链接与重定向
2. **资源解析**：解析下载资源元数据、来源域名与文件特征，评估风险等级
3. **下载确认**：高风险文件弹出确认提示，告知用户具体风险来源与类型
4. **浏览器拦截**：利用浏览器原生 API 在下载前最后一刻兜底拦截恶意文件

**四、用户反馈驱动的持续迭代**

Issue/Bug 提交 → 分析与定位根因、重构相关模块 → 回归测试、性能与体验调优 → 正式版发布（Firefox + Edge）。

**五、不止检测 · 完整产品体验**

设置页可调参数灵活配置；黑白名单手动管理信任站点；更新检测自动检查规则更新；一键反馈快速提交误报漏报。Firefox 正式发布，Edge 审核中即将上线，GitHub 开源社区协作。

**六、Roadmap**

持续更新规则库覆盖更多钓鱼手法；优化检测算法降低误报率提升准确度；支持更多浏览器（Chrome、Edge 及更多平台）；社区反馈驱动（Issue、PR、样本提交）；性能优化降低资源开销；长期维护迭代——这不是终点，而是起点。

**七、重构成果**

这一轮重构后，插件不再只是验证想法的 demo，而是可长期使用、持续迭代的浏览器安全插件。代码架构重新整理，资源解析流程优化，页面数据采集的性能开销减少，整个插件更稳定、更容易维护。

**八、后续计划**

项目里还有不少 issue 等待解决，还有很多新想法正在开发。这次发布不意味着项目做完，而是进入持续迭代阶段。欢迎参与测试、提交反馈、提供新案例，一起把它打磨得更完善。
