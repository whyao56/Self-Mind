**关于 10 款油猴脚本的推荐整理**

来源：Greasy Fork（国内最方便的脚本网站，需 VPN）。除了关键词搜索，还可按域名查找适用于特定网站的脚本。注意：部分功能聚合型脚本可能捆绑广告甚至后门程序，尽量看清详情页或安装功能单一的脚本。

**一、Greasy Fork**

```
https://greasyfork.org/zh-CN
```

**二、网盘链接检查 + 网盘助手**

自动识别并展开被加密的网盘链接，提前知道资源状态，不必手动破解暗号。网盘助手支持自定义提取码、本地保存提取码，下次自动输入。

脚本搜索：

```
https://greasyfork.org/zh-CN/scripts?q=链接助手
https://greasyfork.org/zh-CN/scripts?q=网盘助手
```

**三、链接助手**

遇到加密程度较高的链接，整段复制粘贴到页面左侧按钮中，自动提取并解锁。支持网盘链接自动预处理免填提取码，自动识别磁力链接、电驴链接等，点击直接调用支持的软件下载，还有重定向功能。

**四、搜索引擎重定向**

去除搜索前排广告，优化页面显示效果。右上角自定义可开关重定向去广告、自动翻页，改变页面样式，启动护眼模式。

脚本搜索：

```
https://greasyfork.org/zh-CN/scripts?q=重定向优化
```

**五、自动无缝翻页**

零配置实现任何网站自动翻页，瀑布流浏览效率远高于手动翻页。无法自动翻页或被平台拦截时，点击空白处或在右上角脚本界面暂停。

**六、搜索引擎聚合**

聚合上百种搜索引擎。搜索结果页面左侧点击链接，用对应搜索引擎再次检索。收录常见国内外搜索引擎及细分引擎（词典、购物平台、视频网站、网盘搜索）。

脚本搜索：

```
https://greasyfork.org/zh-CN/scripts?q=聚合搜索
```

**七、网页加速器**

鼠标停留在链接上时，利用浏览器预加载技术提前加载网页，点击后几乎瞬间打开。

脚本搜索：

```
https://greasyfork.org/zh-CN/scripts?q=网页加速
```

**八、免登录去弹窗**

去除各种登录、下载弹窗，去除页面广告、复制限制。支持知乎、解说、B站等。

脚本搜索：

```
https://greasyfork.org/zh-CN/scripts?q=免登录
```

**九、在线看图工具（Picviewer）**

批量抓图并打包、在线编辑、以图搜图。鼠标放图片上出现黑色按钮：查看当前页所有图片、查看当前图片、全局放大固定显示。小图多一个“查看原图”。图片查看界面可调保存尺寸，右上角可加载下页图片、旋转、放大、翻转、收藏、自动播放。命令中可打包下载当前所有图片。以图搜图整合国内外图片网站，可一键搜索全部。

脚本搜索：

```
https://greasyfork.org/zh-CN/scripts?q=Picviewer
```

**十、购物党比价工具**

安装后在任何购物网站商品价格下方显示历史价格，方便判断是否该买。精简版不含广告和推广。

脚本搜索：

```
https://greasyfork.org/zh-CN/scripts?q=比价
```
