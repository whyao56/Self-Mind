**关于在电脑本地使用 DeepSeek V4 Pro API 版本的完整教程**

通过这个教程，可以调用 DeepSeek V4 Pro 官方 API 在电脑上进行日常对话，并开启 V4 Pro 最大思考强度获得最高质量回答。适合需要与 DeepSeek V4 Pro 进行高质量对话和流畅体验的用户。

**第一步：充值并申请 API Key**

1. 登录 DeepSeek 官方网站，英文版点右上角切换中文。
2. 点击“API 开放平台”，输入手机号（DeepSeek 账号）。
3. 点击充值，选择支付宝或微信支付，可自定义金额（如先充 10 元或 5 元）。
4. 支付后申请 API Key：点击“API Key” → “创建 API Key”，名字随便写。
5. 获得密钥后**先保存下来**，密钥只展示一次。忘记需要重新申请。

**第二步：下载 Cherry Studio**

- 点击下载 V1.9.3 版本，立即下载（Mac 用户可选 Mac 版本）。
- 按正常软件指示安装。

Cherry Studio 是与大模型交互的软件。打开后页面可能不同，跟着操作即可。左下角月亮图标可切换黑色/太阳（浅色）主题。

**第三步：配置 DeepSeek**

1. 点击左下角齿轮“设置” → “模型服务” → 选择“深度求索”。
2. 右上角打开它。
3. 在“API 密钥”处粘贴刚才的 API Key。
4. “模型”处可能为空，点击右边“获取模型列表”，出现两个新 DeepSeek：**V4 Pro** 和 **V4 Flash**，都可加入列表（按需调用 Flash）。

**第四步：创建助手并设置 V4 Pro**

1. 返回左上角“助手” → “添加助手” → “默认助手”。
2. 默认显示一个 AI 模型，直接搜索“V4”，选择 V4 Pro。
3. 左上角“默认助手”：上下文长度拉到最大“无限”，最大工具调用次数关掉。

**第五步：设置最大推理强度**

点击两次“添加参数”：

- **参数一**：`reasoning effort`，选项为文本，写成 `max`。
- **参数二**：`thinking`，调为 JSON 格式，输入框填入对应内容，点击空白处保存。

**提示词设置**：建议设置成指定提示词，DeepSeek 的回答会更客观。

**助手名字**：可改成“DeepSeek V4 Pro”，点击空白处保存，关闭。

**第六步：开启联网搜索**

点击“网络搜索”，打开“模型内置”选项。

**测试**

可以看到它已开启思考模式并回答问题。

**文档问答**

点击“上传文档”或直接把文档拖进来，可进行 OCR 识别。

**话题管理**

左边“话题”是每次和 DeepSeek 的对话。新建对话：左上角“新建话题”，或左下角“新话题”/Ctrl+N。

**自动生成标题**

默认新话题只显示“个人话题”或“新话题”标签，不会根据对话生成标题。设置方法：点击左边“设置” → “默认模型” → “快速模型”调为“深度求索的 chat”。之后问“今天的北京天气如何”，DeepSeek 搜索并深度思考后，左上角标题自动变为“今日北京天气”。

标题可右键“再次生成”，或点击“编辑话题”写任何希望的名字。
