**关于 Win10/Win11 定时关机的操作整理**

电脑上正干活需要离开一段时间，但电脑没关机，希望在指定时间自动关机。设置里找不到相关选项，用运行命令解决。

**设置定时关机**

`Win+R` 打开运行对话框（或右键开始菜单 → 运行），输入：

```
shutdown -s -t 秒数
```

注意：按**秒**计算。比如两小时后关机是 7200 秒，一小时后关机是 3600 秒，两分钟后关机是 120 秒。

按回车，弹出“即将注销你的登录”提示，说明设置成功，关闭即可。

**取消定时关机**

`Win+R` 打开运行，把 `-s` 改成 `-a`：

```
shutdown -a
```

提示注销被取消，说明关机命令已取消。

**注意**

如果不弹出提示，说明命令输入错误。这个方法适用于 Win10 和 Win11，不用安装第三方软件，最方便。
